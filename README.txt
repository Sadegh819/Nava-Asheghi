Nava Ashaghi - راهنمای پروژه

محتویات بسته
-------------
1) index.html
   فایل اصلی سایت است. کد HTML، CSS و JavaScript همگی داخل همین فایل قرار دارند.

2) پوشه audio
   شامل ۱۰ فایل صوتی MP3 است که پخش‌کننده سایت از آن‌ها استفاده می‌کند.

راه‌اندازی روی کامپیوتر یا گوشی
-------------------------------
- فایل ZIP را از حالت فشرده خارج کنید.
- فایل index.html را در مرورگر باز کنید.
- پوشه audio را در کنار index.html نگه دارید؛ نام پوشه را تغییر ندهید.

انتشار در GitHub Pages
----------------------
1) وارد مخزن GitHub خود شوید.
2) فایل index.html و کل پوشه audio را در ریشه مخزن آپلود کنید.
3) مطمئن شوید فایل‌های MP3 داخل مسیر audio/ قرار دارند.
4) در Settings > Pages، انتشار از شاخه موردنظر (معمولاً main و پوشه /(root)) را فعال کنید.
5) پس از انتشار، آدرس GitHub Pages را باز کنید.

نکات مهم
---------
- فقط آپلود کردن index.html کافی نیست؛ فایل‌های صوتی نیز باید آپلود شوند.
- ساختار مسیرها را حفظ کنید: index.html و پوشه audio باید کنار هم باشند.
- برای اضافه کردن مداحی جدید، فایل MP3 را به پوشه audio اضافه کنید و فهرست TRACKS را در انتهای بخش script داخل index.html با عنوان و مسیر آن به‌روزرسانی کنید.
- این پروژه پنل مدیریت ندارد.
- سایت برای نمایش فهرست و پخش فایل‌ها به فایل‌های موجود در پوشه audio نیاز دارد.
